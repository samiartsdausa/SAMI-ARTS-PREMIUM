# SAMI ARTS Website

A responsive Next.js 15 starter website for SAMI ARTS — Premium Printing & Interior Branding Studio.

## Included
- Premium dark navy, white and gold visual design
- Services and indicative pricing
- Inspiration gallery with category filters
- Wall photo upload preview
- Square-foot price calculator
- WhatsApp quote form and service enquiry buttons
- Call, email, Instagram and contact details
- FAQ, responsive mobile menu, metadata and Open Graph

## Run locally
Install Node.js 20.9 or later, then in this folder run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build for production
```bash
npm run build
npm start
```

## Deploy
Push this folder to a GitHub repository and import it into Vercel. Add the domain `samiarts.co.in` in the Vercel project settings and follow Vercel's DNS instructions.

## Before publishing
1. Replace the text SA badge with the official SAMI ARTS logo in `app/page.tsx`.
2. Replace inspiration photos with your real project photos and ensure you have rights to use them.
3. Test the phone, email, Instagram and WhatsApp details.
4. Confirm current pricing, installation terms and service area.
5. Add any final logo, project gallery, and real testimonials.
